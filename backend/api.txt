# EmotiCare API Documentation
# Base URL: http://localhost:8000
# All API endpoints are prefixed with /api/v1/

## Root Endpoints

### GET / (Welcome)
**Curl Command:**
```bash
curl -X GET "http://localhost:8000/" \
  -H "accept: application/json"
```

**Example Return:**
```json
{
  "message": "Welcome to EmotiCare",
  "description": "Digital Mental Health and Psychological Support System for Students",
  "version": "1.0.0",
  "docs": "/docs"
}
```

### GET /health (Health Check)
**Curl Command:**
```bash
curl -X GET "http://localhost:8000/health" \
  -H "accept: application/json"
```

**Example Return:**
```json
{
  "status": "healthy",
  "app_name": "EmotiCare",
  "version": "1.0.0"
}
```

## Authentication API (/api/v1/auth)

**Curl Command:**
```bash
curl -X POST "http://localhost:8000/api/v1/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "student@example.com",
    "password": "SecurePass123!",
    "full_name": "John Doe",
    "role": "student",
    "student_id": "STU001",
    "department": "Computer Science",
    "year_of_study": 2,
    "gender": "male",
    "age": 20,
    "phone_number": "+1234567890",
```

```bash
curl -X POST "http://localhost:8000/api/v1/chat/start-session" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "initial_message": "I'm feeling stressed about my exams",
    "emotional_state": "anxious"
```

## Voice Chat API (/api/v1/voice)

### WebSocket /api/v1/voice/ws/voice-chat (Voice Chat WebSocket)
**WebSocket Connection:**
```javascript
// JavaScript example for connecting to voice chat
const ws = new WebSocket('ws://localhost:8000/api/v1/voice/ws/voice-chat?token=YOUR_ACCESS_TOKEN');

// Send audio chunk
ws.send(JSON.stringify({
  type: 'audio_chunk',
  audio_data: 'base64_encoded_audio_data',
  format: 'wav',
  sample_rate: 16000
}));

// Send text input
ws.send(JSON.stringify({
  type: 'text_input',
  text: 'Hello, I need some support'
}));

// Send ping to keep connection alive
ws.send(JSON.stringify({
  type: 'ping'
}));

// End session
ws.send(JSON.stringify({
  type: 'end_session'
}));
```

## Notes

1. **Authentication**: Most endpoints require a Bearer token in the Authorization header
2. **Admin Access**: Some endpoints require admin or counselor role
3. **WebSocket**: Voice chat uses WebSocket for real-time communication
4. **File Uploads**: Some endpoints may support file uploads (not fully documented here)
5. **Pagination**: List endpoints support `skip` and `limit` parameters
6. **Date Format**: Use YYYY-MM-DD format for dates
7. **Time Format**: Use HH:MM format for times
8. **Base64 Encoding**: Audio data is sent as base64 encoded strings
9. **CORS**: The API supports cross-origin requests from configured domains
