## Voice Chat API (/api/v1/voice)

### WebSocket /api/v1/voice/ws/voice-chat
command - WebSocket connection to ws://localhost:8000/api/v1/voice/ws/voice-chat?token=YOUR_TOKEN
return - WebSocket connection established for voice chat

Message Types (Client to Server):
1. Audio Input:
   {"type": "audio_chunk", "audio_data": "base64_encoded_audio", "format": "wav", "sample_rate": 16000}
   
2. Text Input:
   {"type": "text_input", "text": "user message"}
   
3. Keep-Alive:
   {"type": "ping"}
   
4. End Session:
   {"type": "end_session"}

Message Types (Server to Client):
1. Welcome Message:
   {"type": "welcome", "message": "Hello [name], I'm here to listen...", "session_id": "uuid", "timestamp": "ISO_date"}
   
2. Voice Transcript:
   {"type": "transcript", "text": "transcribed_text", "timestamp": "ISO_date"}
   
3. Text Response:
   {"type": "text_response", "text": "AI response", "timestamp": "ISO_date"}
   
4. Audio Response:
   {"type": "audio_response", "audio_data": "base64_audio", "format": "wav", "timestamp": "ISO_date"}
   
5. Status Updates:
   {"type": "status", "message": "Processing your voice message...", "timestamp": "ISO_date"}
   
6. Crisis Alert:
   {"type": "crisis_alert", "message": "crisis support message", "resources": [crisis_resources], "timestamp": "ISO_date"}
   
7. Error Messages:
   {"type": "error", "message": "error description", "timestamp": "ISO_date"}
   
8. Ping Response:
   {"type": "pong", "timestamp": "ISO_date"}

Features:
- Real-time voice transcription using Azure Speech Services
- Mental health-focused AI responses
- Crisis detection and intervention
- Personalized user context
- Audio response synthesis (text-to-speech)
- Session management with unique session IDs
- Authentication via JWT token in WebSocket URL
